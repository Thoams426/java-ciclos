# CONCLUSIONES
1. Las estructuras repetitivas (`for`, `while`, `do-while`) son fundamentales para la optimización de código en Java, permitiendo procesar iteraciones numéricas complejas sin duplicar código.
2. La elección de la estructura adecuada varía según el problema: `do-while` destaca en la validación de entrada de datos (como restringir números negativos en factoriales y potencias), `while` para bucles condicionales indefinidos, y `for` para rangos o conteos prefijados.
3. La combinación de ciclos con el manejo de cadenas de texto (`String`) facilita la descomposición e inspección de dígitos individuales en problemas avanzados de ordenamiento y suma de cifras.
